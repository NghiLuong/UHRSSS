HƯỚNG DẪN CÀI EXTENSION PGREEN UHRS JUNK SHORTCUTS

Mục đích:
- Dùng phím tắt để chọn nhanh các radio button trong trang UHRS Junk Type.
- Dùng phím tắt để copy link ẩn trong input id="sja_DocumentUrl".

PHÍM TẮT ĐÃ CÀI

Ctrl + Shift + 1: Chọn Not Junk | id: notjunkButton
Ctrl + Shift + 2: Chọn Error Message / Page not found / No results | id: junkButton4
Ctrl + Shift + 3: Chọn Low / No Content / Ads only pages | id: junkButton5
Ctrl + Shift + 4: Chọn Site unreachable | id: junkButton11
Ctrl + Shift + 5: Chọn Automatic Redirection | id: junkButton10
Ctrl + Shift + 6: Chọn Other type of Junk | id: junkButton8
Ctrl + Shift + 7: Copy link ẩn từ input id="sja_DocumentUrl"

Lưu ý:
- Chức năng này chỉ chọn radio button, chưa tự bấm Submit.
- Mục "Can't Judge" chưa gán phím vì Ctrl + Shift + 7 đã dùng cho copy link theo yêu cầu.
- Nếu muốn thêm phím cho "Can't Judge", có thể gán tiếp Ctrl + Shift + 8.

CÁCH CÀI

1. Giải nén file ZIP này ra một thư mục cố định.
2. Mở Chrome hoặc Edge.
3. Vào chrome://extensions hoặc edge://extensions
4. Bật Developer mode / Chế độ nhà phát triển.
5. Bấm Load unpacked / Tải tiện ích đã giải nén.
6. Chọn thư mục đã giải nén.
7. Mở trang UHRS cần thao tác và dùng phím tắt.

CÁCH ĐỔI PHÍM TẮT

Chrome: chrome://extensions/shortcuts
Edge: edge://extensions/shortcuts

Sau đó tìm "PGreen UHRS Junk Shortcuts" và đổi phím theo ý muốn.

XỬ LÝ NẾU PHÍM KHÔNG HOẠT ĐỘNG

1. Kiểm tra extension đã bật chưa.
2. Vào trang shortcuts để xem Chrome/Edge có nhận đủ phím tắt chưa.
3. Nếu phím bị trùng với hệ thống hoặc extension khác, đổi sang tổ hợp khác.
4. Extension không chạy trên trang chrome://, edge://, file://.
5. Với trang UHRS thật, nên click vào tab UHRS trước rồi bấm phím.
